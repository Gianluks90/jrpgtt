# Starting a New Game in Amulet

---

You can start a new game in Amulet as long as you are not currently participating in an ongoing game or have previously created one. From the title page, simply click on "New Game" to move to the game setup. Before that, you will be asked for a title and the number of players (from 1 to 4).

Currently, even from the so-called "lobby," there are no other configurable options for the game besides the title and the number of players. From the _lobby_, you can proceed to configure your character, wait for the others to do the same, and then start the actual game.
