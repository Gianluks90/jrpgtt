# Joining a Game

---

The player who owns a game has access to a unique 6-digit code generated at the time of the game's creation. By sharing this code with other players, they can access the character setup screen and subsequently the actual game. To access the code entry screen, simply click on "Join Game" from the title page. Alternatively, if you have previously participated in a game, you can access the code entry screen directly from the _lobby_.
